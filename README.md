# WEBD 172 - Homework 4: Okinawa Travel Destinations

This project demonstrates Node.js and Express concepts from Weeks 3-4.

## Setup
1. Open the project folder in VS Code.
2. Run `npm install`.
3. Run `npm start`.
4. Open `http://localhost:3000`.

## Routes
- `/` - static home page
- `/about` - HTML generated by Express
- `/api/destinations` - all destinations as JSON
- `/api/destinations/:id` - one destination by route parameter

## Concepts
Node.js, npm, package.json, Express, middleware, static files, routes,
JSON responses, route parameters, status codes, fetch(), async/await,
and destructuring.
